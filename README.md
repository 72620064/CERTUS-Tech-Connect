# Certus-Tech-Connect 🌐🚀

**Certus-Tech-Connect** es una solución tecnológica e institucional diseñada como una plataforma web y red social de networking académico-profesional para potenciar el talento de los estudiantes y egresados de las carreras de TI de CERTUS. 

La plataforma mitiga la dispersión de información y la desconexión estudiantil mediante un ecosistema digital unificado que integra perfiles técnicos (orientados al *stack* tecnológico por ciclos), un *feed* de noticias del sector, un módulo automatizado para la gestión e inscripción a concursos y hackatones, y un sistema dinámico de interacción social. El proyecto está estructurado bajo arquitecturas modernas y escalables que garantizan su viabilidad técnica, sostenibilidad operativa a largo plazo y la consolidación de una base de datos de talento calificado de la institución.
